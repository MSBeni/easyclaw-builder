# Contributing

This repository is under active extraction from an older fork. Before proposing a change, open an issue describing the behavior and the OpenClaw version tested. Keep changes scoped to the Builder and avoid copying Gateway, channel, authentication, or native-app code.

Use fake data in tests and examples. Never commit personal briefs, live credentials, local config, generated packages, or screenshots containing account details. Include a test for behavior changes and call out any OpenClaw API or schema assumptions.
