# Security policy

EasyClaw Builder is pre-release and has no supported versions yet. Please report a suspected vulnerability through the repository's private security-advisory channel. Do not open a public issue containing credentials or an exploit.

The Builder handles operator-authored briefs and may eventually run as a trusted OpenClaw feature plugin. Treat plugin installation as granting access to the operator's OpenClaw Gateway. Generated Claw packages must be previewed before installation and must not embed credentials, private configuration, or channel destinations.

Security problems in OpenClaw itself should be reported to [OpenClaw](https://github.com/openclaw/openclaw/security/policy), not this repository.
